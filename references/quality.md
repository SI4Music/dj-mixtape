# Quality and delivery

Check each prepared recording's exact selected frame count, as well as the rendered candidate's duration, sample rate/channels, finite samples, sample peak, integrated loudness, true peak, transition windows and unexplained silence. Already mastered music often needs level adjustment more than additional compression. Measure loudness after rendering; limiting does not replace bass management.

Retain current hashes for plan, source/prepared clips, output and relevant scripts. Compare overlapping media sum to the pre-master render and verify the master gain. Fix actual failures then rerun affected checks; a description edit does not justify another full render.

Distinguish technical PASS from subjective listening. Where cues were model-selected without human/audio-perception review, say that phrase/vocal coherence still needs listening assessment. Do not claim professional quality or perfect transitions.

Deliver full WAV, MP3, editable project, source provenance, tracklist/timestamps, transition recipe and verification receipt. Use one streaming media element for the full set. The audio-layer-player skill can inspect short aligned transition stems, not decode many one-hour stems into memory.

Bind listening server to loopback and preserve existing playback by using another free port. Publishing the mix is outside a local creation request.
